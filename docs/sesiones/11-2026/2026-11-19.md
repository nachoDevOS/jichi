### Solución
Se agregó una API con token de Sanctum, uno por celular, que **reusa** el ingreso
del portal en vez de copiarlo: misma búsqueda de la C.I., mismo mensaje, mismo tope
de 5 intentos por C.I. + IP (compartido con la web) y mismo registro en `accesos`.
Con la clave temporal solo se puede ver la cuenta, cambiarla o salir, igual que en
la web. El token no vence solo: lo cortan salir, «Resetear contraseña»,
«Desactivar acceso» y cambiar la clave.

**Antes:**
```php
public function authenticate(): void
{
    $this->ensureIsNotRateLimited();
    // ... C.I. y clave ...
    Auth::guard('web')->login($cuenta);
}
```

**Después:**
```php
public function authenticate(): void
{
    $cuenta = $this->cuentaValida();   // la usa también IngresarAppRequest
    Auth::guard('web')->login($cuenta);
    $this->registrarAcceso('login', $cuenta->id);
}
```

- **La piscicultura no se ofrece**, igual que en el panel (`MOSTRAR_PISCICULTURA = false`):
